# APEXLOT asset pipeline

- models/: original GLB/GLTF vehicle, building and prop exports from Blender.
- textures/: original PBR Base Color, Roughness, Metallic and Normal maps.
- audio/: original or properly licensed engine, ambience and UI audio.
- Export glTF 2.0 for the Three.js web runtime; apply transforms and name objects clearly.
- Use sensible polygon budgets and test mobile texture sizes.
- Do not import proprietary assets from other games.
